Blog Técnico: Mentalidad de Crecimiento

Este blog documenta un caso práctico de aprendizaje en desarrollo de software utilizando control de versiones y análisis post-mortem.

Contexto

Durante un proyecto de desarrollo, enfrenté dificultades técnicas relacionadas con errores inesperados en el sistema.

Problema

Los errores impedían el correcto funcionamiento de la aplicación y afectaban el flujo de trabajo.

Acciones

  • Análisis de errores
  • Revisión de documentación
  • Aplicación de post-mortem constructivo
  • Uso de Git para control de versiones

Aprendizajes

Aprendí que los errores son parte del proceso de desarrollo y que la mentalidad de crecimiento es clave para mejorar como programador.
